Reaction lag

You laugh, then you reach for the key, so the press lands after the joke. Laugh rewinds every mark by this much to estimate where the punchline actually was. Changing it also re-times the moments you already saved, because the raw press time is kept.

Laugh window

Presses this close together count as one laugh with an intensity, rather than several separate moments.

YouTube Data API key

With a key, the feed can go looking for videos that match your profile. It is free: create a project in the Google Cloud console, enable the YouTube Data API v3, and make an API key. Restrict that key to the YouTube Data API. It is stored only in this browser and is never included in an export.
